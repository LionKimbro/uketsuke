# UKETSUKE BOUNDARY

These are the host capabilities and directory facts that uketsuke
receives through configuration.  The host owns the actual operating
system work; uketsuke calls these operations through fsio or its
configured host functions.


## CONFIGURATION

configuration contains these required sections:

```text
host-os-functionality  dictionary of host filesystem callables
host-functions          dictionary of host request/work callables
directories             dictionary of configured pathlib.Path values
```

### HOST-OS-FUNCTIONALITY

```text
read-file        callable(pathlib.Path) -> bytes
write-and-sync   callable(pathlib.Path, bytes) -> None
copy-and-sync    callable(pathlib.Path src, pathlib.Path dest) -> None
delete-and-sync  callable(pathlib.Path) -> None
mkdir-and-sync   callable(pathlib.Path) -> None
list-files       callable(pathlib.Path) -> list[file description]
```

### HOST-FUNCTIONS

```text
summarize-request  callable(pathlib.Path) -> request ID string
dispatch-job       callable(job dictionary) -> JSON-safe value
send-reply         callable(job dictionary) -> None
```

### DIRECTORIES

```text
inbox       pathlib.Path
work-space  pathlib.Path
```


## DIRECTORY TREE

configuration provides:

```text
inbox       intended location of incoming opaque request files
work-space  intended location of uketsuke's working tree
```

startup creates or verifies:

```text
inbox/
work-space/
  working/
  done/
  dead-letter/
```

directory rule: uketsuke creates the configured inbox and work-space
directories when absent, but never creates their missing parents.


## HOST FILESYSTEM OPERATIONS

### READ-FILE

accepts: src (path)
returns: bytes
raises: FileNotFoundError if absent; otherwise host failure unchanged


### WRITE-AND-SYNC

accepts: destination (path); content (bytes)
returns: nothing
ensures: a successful write has reached the host's durability boundary
raises: host failure unchanged


### COPY-AND-SYNC

accepts: src (path); destination (different path)
returns: nothing
ensures: a successful copy has reached the host's durability boundary
raises: host failure unchanged


### DELETE-AND-SYNC

accepts: path (path)
returns: nothing
ensures: a successful deletion has reached the host's durability boundary
raises: FileNotFoundError if absent; otherwise host failure unchanged


### MKDIR-AND-SYNC

accepts: path (path)
allows: path already exists
requires: an absent path has an existing immediate parent
does not: create absent parent directories
returns: nothing
ensures: path exists; a new directory has reached the host's durability boundary
raises: host failure unchanged


### LIST-FILES

accepts: path (directory path)
returns: one description for each immediate file in that directory:

```text
{
  "path": the file path,
  "last-modified": seconds since the Unix epoch,
}
```

does not: recurse into child directories or return directories
raises: host failure unchanged


## HOST FUNCTIONS

### SUMMARIZE-REQUEST

|               |                                                                                        |
| ------------- | -------------------------------------------------------------------------------------- |
| **Signature** | `summarize-request(request_file_path: pathlib.Path)`                                   |
| **Returns**   | `request-id` (`str`)                                                                   |
| **Raises**    | Any exception if the request is malformed, unrecognized, or otherwise incomprehensible |

Examines the opaque request at `request_file_path` to decide whether
Uketsuke can accept it, and returns its `request-id` if it can.
Otherwise, it raises an exception.

The host owns interpreting the opaque request. Uketsuke records any
resulting error in the dead-letter job.

There is never more than one job for a given `request-id`.


### DISPATCH-JOB

|               |                                                            |
| ------------- | ---------------------------------------------------------- |
| **Signature** | `dispatch-job(job: dict)`                                  |
| **Returns**   | A JSON-safe response value                                 |
| **Raises**    | Any exception if the host cannot complete the job          |

Receives the current job record and performs its requested work. The
host owns interpreting the opaque request and choosing the work to do.

Uketsuke stores a normal return value in `job["response"]`. It records a
raised exception in `job["error"]`. The host must return only JSON-safe
data: `None`, strings, numbers, booleans, lists, dictionaries, and
structures composed from them. Uketsuke does not validate that promise.

The host must make dispatch idempotent by `job["request-id"]`.

idempotence is essential: a crash can occur after dispatch begins but
before uketsuke records its result.  Startup then resets that job for
re-execution, so dispatch-job may receive the same request-id again.


### SEND-REPLY

|               |                                                                       |
| ------------- | --------------------------------------------------------------------- |
| **Signature** | `send-reply(job: dict)`                                               |
| **Returns**   | `None`                                                                |
| **Raises**    | Any exception if the host cannot complete its reply-delivery attempt  |

Receives an executed job and determines whether a reply is wanted. If
one is wanted, the host constructs and delivers the opaque reply in its
own format. If none is wanted, it returns normally without sending one.

The host owns interpreting the opaque request and all reply structure
and delivery mechanics. Uketsuke marks a normal return as reported. It
records a raised exception in `job["error"]` and leaves the job executed
for another delivery attempt.

The host must make reply delivery idempotent by `job["request-id"]`.

idempotence is essential: a crash can occur after reply delivery begins
but before uketsuke records that it was reported, so send-reply may
receive the same request-id again.
